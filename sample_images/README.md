# Примеры изображений

В эту папку можно положить несколько изображений для демонстрации Streamlit-приложения.

Рекомендуемый набор:

- фото здорового листа томата;
- фото листа с альтернариозом;
- фото листа с фитофторозом;
- одно неподходящее изображение для демонстрации правила `R1`.

Датасет для обучения сюда класть не нужно. Датасет должен находиться в папке `dataset` в структуре, описанной в основном `README.md`.
